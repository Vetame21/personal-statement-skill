# Thesis Debate Panel

Rules: `shared/debate-rules.md` (in short: no instant agreement, research before factual verdicts, steelman both sides, change position only for evidence or a better argument). Write each panelist's view before reading the others, then let them clash. Use parallel subagents only when the environment supports them and the user asked for a deep debate; otherwise play the roles in sequence.

## Panelists

| Panelist | Reads as | Pushes for | Typical attack |
|---|---|---|---|
| **Examiner (Penguji)** | An external examiner scoring against the rubric | Rigor, clear contribution, answered research questions | "Your rumusan masalah 2 is never answered in Bab IV." |
| **Supervisor (Pembimbing)** | The student's supervisor who wants them to finish on time | Feasibility, scope, steady progress | "This needs data you can't get before the deadline. Narrow it." |
| **Methodologist (Skeptic)** | A statistician or senior researcher | Valid method, correct analysis, honest claims, real sources | "n = 30 from one class can't support 'mahasiswa Indonesia'." |
| **Tone Detector** | A reader tired of machine-written theses | Plain, specific academic language in the right register | "'Di era digital yang semakin berkembang' in the first line." |
| **Moderator** (you) | Neutral | A decision and a next step | Verdicts and scores |

## Debate 1: topic (before writing)

1. Motions: each candidate topic, or decisions like "use survey data", "build a system and evaluate it", "compare three models".
2. Each panelist: For / Against / Conditional + one reason. Methodologist checks feasibility and whether the gap is real (search for 2-3 prior studies when possible).
3. Moderator verdict per motion: **Go / Narrow it / Change it**, with the narrowed version written out (title, 1-3 research questions, data, method, success measure).

## Debate 2: examiner simulation (after a draft)

1. **Attacks**: each panelist names its top 3 problems with a short quote or location (chapter, section, table) and a fix.
2. **Clash**: each panelist answers one other panelist's strongest point (e.g. Supervisor vs Examiner on scope; Methodologist vs Supervisor on sample size).
3. **Verdicts**:

| # | Issue (location) | Raised by | Verdict | Fix |
|---|---|---|---|---|
| 1 | ... | Examiner | Fix now / Explain in defense / Student's call | ... |

4. **Scores** using the sheet in `what-examiners-want.md` (or the campus rubric).
5. **Top 3 likely defense questions** from this draft, with answer outlines.

Quick mode by default (one clash round); "deep" on request.

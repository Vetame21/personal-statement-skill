# debate-mode

Evidence-first debate. Instead of agreeing, Claude researches a claim or proposal and returns a sourced verdict (Yes / No / Partly / Not enough evidence) before giving a recommendation. Use when the user asks Claude to debate, argue, challenge them, push back, fact-check, "debat pakai fakta", "jangan iya-iya aja", "don't just agree", "prove it", or asks whether an idea, claim, or edit (for example to a personal statement or CV) is right or relevant.

# debate-mode

Evidence-first debate. Instead of agreeing, the agent researches a claim or proposal and returns a sourced verdict (Yes / No / Partly / Not enough evidence) before giving a recommendation. Use when the user explicitly asks the agent to debate, argue, challenge them, push back or fact-check ("debat pakai fakta", "jangan iya-iya aja", "don't just agree", "prove it"), or asks for a researched, sourced verdict on a claim or on a proposed change to a statement or CV. Not for ordinary questions or requests for opinions.
